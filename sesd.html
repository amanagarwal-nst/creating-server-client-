From one chai stall to one crore users

An 8-hour system design course told through ChaiChain, Raju's chai stall that grows into a nationwide app. Each module adds one box to the system below, because something broke without it. Every module follows the same rhythm: predict, learn, build the architecture, play, bust myths, discuss, and check yourself.
