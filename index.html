Finds addressDNS Returns the IP to the client
  1. You tap in the Client; it asks DNS for the IP behind instagram.com.
  2. DNS sends that IP straight back to the Client — DNS is out of the loop after this.
  3. The Client uses the IP to send its request to the Server.
  4. The Server queries the Database for the posts.
  5. The Database returns the rows to the Server.
  6. The Server sends the response back down to the Client, and your feed appears.
